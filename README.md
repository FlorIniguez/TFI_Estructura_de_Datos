📦 Sistema de Gestión de Envíos — TFI Estructura de Datos

Este proyecto implementa un sistema de gestión logística utilizando todas las estructuras de datos vistas en la materia:
Árbol binario de búsqueda, Heap, Árbol general, Grafos, BFS/DFS, Dijkstra y Orden Topológico.

El sistema permite gestionar paquetes, ver historiales, simular envíos y calcular rutas entre sucursales del país.

## 🚀 Funcionalidades principales

✔ Registrar nuevos paquetes  
✔ Almacenar paquetes en un Árbol Binario de Búsqueda (ABB)  
✔ Procesar paquetes por prioridad mediante un MinHeap  
✔ Consultar historial de un paquete (Árbol General)  
✔ Calcular caminos entre sucursales mediante:  
   - BFS (camino más corto en tramos)  
   - DFS (verificar si existe un camino)  
   - Dijkstra (camino mínimo por distancia en km)  
✔ Generar un orden topológico en grafos dirigidos  
✔ Menú interactivo para probar todo
